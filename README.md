# Vigraha Engineering Website

A responsive Vite + React starter website for Vigraha Engineering, based on the uploaded **Website Color Scheme** PDF.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (typically http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

Deploy the generated `dist/` directory to any static hosting provider.

## Before going live

- Replace `hello@vigrahaengineering.com` with the **verified company email**. It is a placeholder, not a confirmed address.
- Review the **starter service descriptions**, capabilities, and process copy against the company's actual offerings.
- The quote form launches a pre-composed email through the visitor's mail application. It does not submit to a server or upload CAD files. For a production form, connect a secure email/form backend.
- The header uses a simplified, logo-inspired mark rather than a standalone vector logo. Replace it with the original logo artwork if available.
- Configure the business's real contact info, policies, SEO/social metadata, and deployment domain.
